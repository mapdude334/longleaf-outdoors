# Alabama / Georgia expansion with a South Carolina pilot

The online catalog extends beyond the original East Alabama / West Georgia map packs. Alabama and Georgia remain the established statewide agency catalogs; selected South Carolina agency catalogs are also present as a source-limited pilot. This is an inventory of mapped records, not a claim that every water, ramp, habitat feature or restroom has been surveyed. Production promotion requires the user's approval.

The original community access and restroom records remain as regional supplements. They have not been relabeled as a statewide OSM inventory. Freshwater and coastal records use the same map-card and trip flows. An explicitly closed agency ramp cannot be chosen as a new launch; a historical status is not proof of current opening.

## Data integrity and refresh

Run `python pipeline/scripts/46_expand_states.py` to refresh the AL/GA sources. It preserves the separately staged SC catalog slices and their state boundary and historical habitat points; it does not refresh those SC sources. Every AL/GA source is read by its complete object-ID list in bounded batches. Missing pages or service failures stop the import before publication. Raw responses are cached in the ignored `pipeline/cache/statewide/` directory for one day. Relevant attribution, source URLs, record IDs, source-layer edit dates when supplied, installation/observation dates and retrieval timestamps are preserved. Personal surveyor/editor fields are not copied into the app catalog. The coverage manifest is recomputed from the exact catalogs written by either pipeline.

`public/data/coverage.json` records catalog totals and per-state counts, source counts, accepted/excluded counts, edition information, and open reuse-review flags. The current data package contains 2,820 access points, 5,289 structure points, 886 facility-restroom points, 7,660 habitat points, three state outlines, and 784 destinations. South Carolina contributes 1,030 access points, 129 fish-structure points, 265 facility-restroom points, 257 historical habitat points, and 287 new destination groups; its data caveats and open source-terms review are documented in the pilot note. These counts are snapshots and do not imply exhaustive coverage.

`pipeline/statewide-water-profiles.json` contains a small set of manually checked agency fishery profiles. Existing curated species and notes are preserved. Other species lists use explicit source flags; absent data receives an explanation, not a guessed species list. Species lacking a full field-guide entry open an honest source-information card instead of a dead control.

Run `npm run test:statewide`, `npm run test:regions`, `npm run test:preview` and `npm run build` before publishing. Statewide tests verify original records and destination IDs remain, new points exist beyond the core area, source/category metadata is present, access points refer to valid destinations, and regional archives cannot suppress statewide access points. The preview publisher runs these checks.

## Online and offline behavior

The original PMTiles coverage and checksums are unchanged. Catalog JSON and symbols are included in the app's service-worker cache. Outside the archive footprint, the map uses online topo when the regional vector base was selected, and online land/water layers instead of clipped archive overlays. Saved imagery selection is respected. Public-land identify works there too. Use area downloads for basemap/terrain coverage beyond the original archives and verify on the device before departure. Parcel coverage remains limited to the previously configured counties.

This expansion does not add marine navigation charts or automatic safe-water routing. Gulf/Atlantic reef coordinates, historical habitat records and terrain contours are not a marine depth survey.
